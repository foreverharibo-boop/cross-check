# 🔀크로스체크

SillyTavern에서 동시에 작동하는 확장과 CSS를 교차 검사하는 진단 확장입니다.

## 주요 기능

- 현재 로드된 확장 JS와 CSS 출처 수집
- 동일 선택자·속성에 서로 다른 값을 지정한 CSS 충돌 후보 검사
- Persistent Custom CSS의 항목 제목, 폴더, 활성 상태를 구분하여 검사
- 비활성 등록 CSS를 켰을 때 생길 수 있는 잠재 충돌 검사
- 화면 요소를 직접 선택하여 그 요소에 동시에 적용되는 CSS 비교
- 중복 DOM ID, 확장 manifest 이상, 최근 브라우저 오류 확인
- 진단 결과 텍스트 복사

## 사용법

1. SillyTavern의 확장 설정에서 `🔀크로스체크`를 펼칩니다.
2. `전체 검사`를 누르면 로드된 확장과 CSS를 검사합니다.
3. 화면에서 문제가 보이는 요소가 있다면 `요소 선택`을 누른 뒤 해당 요소를 터치합니다.
4. 결과 창에서 현재 적용값, 충돌 규칙, 출처를 확인합니다.

## 참고

- 전체 검사는 코드상 겹침을 찾아내므로 결과를 `충돌 후보`로 표시합니다.
- 요소 선택 검사는 현재 화면의 실제 요소에 함께 적용되는 규칙만 비교하므로 더 정확합니다.
- 외부 도메인의 CSS는 브라우저 보안 정책 때문에 내부 규칙을 읽지 못할 수 있습니다.
- 번들 또는 동적 코드 내부의 의미상 충돌까지 100% 자동 판정하지는 않습니다.
