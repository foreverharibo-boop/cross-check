# 🔀크로스체크

SillyTavern에서 현재 활성화된 외부 확장과 CSS를 교차 검사하는 진단 확장입니다.

## 주요 기능

- 현재 활성화되어 로드된 외부 확장 JS와 CSS 출처 수집
- 현재 켜진 Persistent Custom CSS 항목만 검사
- 같은 선택자·속성·우선순위에서 값이 달라 로드 순서에 따라 결과가 바뀌는 CSS 충돌 검사
- Persistent Custom CSS의 항목 제목과 폴더를 출처로 표시
- 외부 확장끼리 사용하는 전역 JavaScript 이름, 설정 키, 생성 DOM ID 중복 검사
- 의미가 확인되는 최근 브라우저 오류 표시
- 진단 결과 텍스트 복사

## 사용법

1. SillyTavern의 확장 설정에서 `🔀크로스체크`를 펼칩니다.
2. `검사하기`를 누릅니다.
3. 결과 창에서 현재 활성 상태에서 서로 경쟁하는 규칙과 출처를 확인합니다.

## 검사 기준

- 비활성 확장과 꺼진 등록 CSS는 검사 결과에서 제외합니다.
- 현재 화면 폭에서 적용되지 않는 미디어 규칙은 제외합니다.
- SillyTavern 기본 CSS를 테마나 사용자 CSS가 정상적으로 덮는 경우는 제외합니다.
- `!important`처럼 승자가 명확한 의도적 덮어쓰기는 제외합니다.
- 같은 우선순위에서 다른 값을 사용하여 마지막 로드 순서에 따라 결과가 달라지는 경우만 CSS 충돌로 표시합니다.
- 외부 도메인의 CSS는 브라우저 보안 정책 때문에 내부 규칙을 읽지 못할 수 있습니다.
- 번들 또는 동적 코드 내부의 의미상 충돌까지 100% 자동 판정하지는 않습니다.

- 비활성 CSS 잠재 충돌 검사와 요소 선택 기능 제거
- 기본 CSS 정상 덮어쓰기, 우선순위가 명확한 덮어쓰기, 일반 DOM 중복 제거
- 같은 우선순위에서 값이 달라 로드 순서에 의존하는 CSS만 충돌로 표시
